# Prashant Shrestha — Personal Portfolio

Welcome to my personal portfolio repository! This project showcases my work, skills, projects, and interests in technology and web development.

🌐 **Live Website:** [prashantshrestha410.com.np](https://prashantshrestha410.com.np)

## ✨ Features

- Responsive and modern portfolio design
- About and personal introduction section
- Projects and services showcase
- Contact form with email OTP verification
- Supabase backend integration
- Email notifications for contact submissions
- Server-side input validation
- Rate limiting and spam protection
- Kathmandu local-time display

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase
- Resend
- GitHub Pages

## 🔐 Security

The contact system includes:

- Supabase Row Level Security (RLS)
- JWT verification
- Server-side validation
- HTML escaping
- Email verification
- Rate limiting
- Server-side secret management

Private API keys and service-role credentials are not included in this repository.

## 🔒 Privacy Policy

Your privacy matters. This section explains how information submitted through the contact form is handled.

### Information Collected

When you use the contact form, the following information may be collected:

- Name
- Email address
- Project type
- Message
- Submission timestamp

### How Information Is Used

The submitted information is used to:

- Respond to enquiries.
- Understand project requests.
- Send contact notifications.
- Prevent spam and misuse of the contact form.

### Email Verification

Email verification uses a one-time password (OTP) to confirm access to the submitted email address before a message can be sent.

### Data Storage and Third-Party Services

- **Supabase:** Used for authentication, backend processing, and storing contact submissions.
- **Resend:** Used to deliver email notifications.

These services process information as needed to provide their respective functions and are subject to their own privacy policies.

### Data Security

Reasonable technical measures are used to protect submitted information, including access controls, server-side validation, and rate limiting.

However, no internet-based system can guarantee absolute security.

### Data Retention

Contact information may be retained as long as necessary to handle enquiries and for legitimate operational purposes. Retention and deletion depend on the website's database management practices.

### Your Privacy Questions

For questions or requests concerning information submitted through the contact form, please use the contact section of the portfolio.
